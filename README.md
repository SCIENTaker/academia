# 学問の地図(Academia)

分野・概念・問い・人物・学習ルートを、**分類(ツリー)** と **関係(グラフ)** の二層構造でつないだ、学問全体の地図サイトです。

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、GitHub Pages でそのまま公開できます。

```sh
python3 -m http.server   # http://localhost:8000
node scripts/validate.mjs # データの整合性チェック
```

## ページの種類

| 種類 | 内容 | データ |
|---|---|---|
| 分野 | 分類ツリーの節点(物理学、言語学、量子力学…) | `data/fields.js` |
| 概念 | 複数分野にまたがる考え方(エントロピー、自然選択、不完全性定理…) | `data/concepts.js` |
| 問い | 未解決問題・大きな問い(意識とは何か、P≠NP か…) | `data/questions.js` |
| 人物 | 伝記ではなく「何を考え、何を変えたか」 | `data/people.js` |
| 学習ルート | ページを順番につないだ道筋 | `data/routes.js` |

## 分類と関係

- **分類(ツリー)**: 形式科学 / 自然科学 / 社会科学 / 人文学 / 応用科学 → 分野 → 下位分野。分野ページの `parent` でつなぎ、`classification` に日本十進分類法(NDC)と arXiv カテゴリとの対応を持たせています。
- **関係(グラフ)**: `data/relations.js` に `[種類, from, to, 補足?]` の形で書きます。

| 種類 | 意味 |
|---|---|
| `prereq` | 前提知識(A は B を学ぶ前に必要) |
| `develops` | 発展・応用(A から B が生まれた) |
| `tool` | 道具として使う(統計学 → 心理学) |
| `conflict` | 対立・競合する理論(向きなし) |
| `influence` | 歴史的な影響(人物 → 概念も含む) |

## 関係データから作られる機能

- **知識マップ**(`#/map`, `#/map/<id>`): 力学モデルで配置した関係グラフ。ページ種類・関係種類で絞り込み、分類ツリーを重ねて表示できます。
- **学習ルートの自動生成**(`#/build/<id>`): 目標から `prereq` を推移的にさかのぼり、トポロジカルソートして段階ごとに並べます。
- **足りない前提の提示**: 各ページで未学習の前提を表示。分野ページでは「その分野の外にある前提」を集めます。学習済みの記録はブラウザの localStorage にだけ保存されます。

## データの追加

1. 該当する `data/*.js` にページを追加する(`id` は英小文字・数字・ハイフン)。本文では `[[id]]` / `[[id|表示名]]` でリンクできます。
2. `data/relations.js` に関係を追加する。
3. `node scripts/validate.mjs` を実行する。存在しない参照、前提知識の循環、ルート内の順序の誤りなどを検出します。

## 構成

```
index.html        画面の骨組み
css/style.css     スタイル(ライト/ダーク対応)
js/graph.js       索引・ツリー・関係グラフ・前提計算(validate.mjs と共用)
js/map.js         知識マップの配置と描画(外部ライブラリなし)
js/app.js         ルーティングと各画面
data/             ページと関係のデータ
scripts/validate.mjs  データ検査
```
